# Marketplace UMKM Multi-Client

Sistem marketplace produk UMKM multi-client berbasis web menggunakan Laravel 13.

## Requirements

Pastikan perangkat sudah memiliki:

- PHP 8.4+
- Composer 2.x
- Node.js dan npm
- MariaDB/MySQL
- Redis
- Git

## Tech Stack

- Laravel 13
- Livewire 4
- Laravel Fortify
- Livewire Flux
- MariaDB/MySQL
- Redis
- Laravel Reverb
- Vite
- PHPUnit
